# Ecosystem glossary

Product display names map to existing repositories: Overstory (`agent-webui`),
Tuig (`agent-terminal-ui`), Scion SDK (`agent-connector-sdk`), Trellis
(`agent-utilities`) and Axil Desk (`geniusbot`). Package/import names and
repository URLs are unchanged. The Tuig executable remains `tuig`.

<a id="arbora-web-ui"></a>

## Overstory

The browser operator experience for working with agents and their runtime. Arbora hosts it as a composed service.

<a id="agent-terminal-ui"></a>

## Tuig

The terminal and headless client for Arbora REST operations.

<a id="geniusbot"></a>

## Axil Desk

The desktop GUI for chat, graph, fleet, health, and operator workflows. Its primary panels use the governed Arbora gateway.

## Messaging channels

Chat and voice entrypoints hosted and supervised by Arbora. The adapter registry, inbound router, and orchestration bridge are implemented by Trellis.

## Arbora

The governed runtime gateway and composition host for user interfaces, messaging channels, MCP, REST, and A2A clients.

<a id="agent-utilities"></a>

## Trellis

The in-run agent harness for run mechanics, context assembly, and governed execution.

## Epistemic Graph

The durable multimodal knowledge and reasoning engine for graph data, evidence, and provenance.

<a id="agent-connector-sdk"></a>

## Scion SDK

The governed source integration boundary for discovering, reading, and synchronizing external systems.

## MCP

The Model Context Protocol, a standard interface for exposing tools and context to AI applications.

## A2A

Agent-to-Agent, a protocol for communication and task exchange between agents.

## OWL

The Web Ontology Language, used to define classes, properties, and logical relationships.

## RDF

The Resource Description Framework, a graph data model for describing resources and their relationships.

## SHACL

The Shapes Constraint Language, used to validate graph data against declared shapes.

## UQL

Unified Query Language, the graph query surface used by the ecosystem.
