# ARBORA-INGRESS requirements

| ID | Requirement | Verification |
|---|---|---|
| `ARBORA-INGRESS-R001` | **Public ingress rename with identity-provider and secret-store cutover (rollup).** Subsystem: deployment, public ingress. Entry: `setup-config` (`arbora/deployment/cli.py`) rendering a profile loaded by `load_environment_profile`. Arbora serves from its own hostname with a renamed TLS certificate, ingress resource and secret. The key lives in the secret store and arrives through an external-secret object. The identity provider redirect URIs are updated, and a time-bounded redirect from the prior hostname exists during cutover. Children: `.1` model, `.2` profile wiring, `.3` legacy redirect, `.4` served probe. Provisioning of the secret store and provider client runs from `services/`. Depends on: `ARBORA-IDENTITY-R024`. | Root journey: `tests/deployment/test_public_ingress_identity.py::test_cutover_probe_signs_in_on_new_hostname` (L6) runs `scripts/identity_probe.py` against the new hostname and asserts MCP and REST answer under the renamed ingress. |
| `ARBORA-INGRESS-R001.1` | **Typed public-ingress profile model.** Subsystem: deployment, public ingress. Code: `arbora/deployment/public_ingress_identity.py::PublicIngressProfile` and `public_ingress_profile_from_mapping`, a closed-schema value object with `version` 1. Caller: `EnvironmentProfile` loading in `arbora/deployment/genesis_environments.py` (`ARBORA-INGRESS-R001.2`). Rule: the profile carries `public_origin`, `tls_secret_ref`, `callback_uri` and `trusted_proxy`. It refuses an unknown or missing key and a malformed TLS reference. It also refuses a callback outside the origin, a non-loopback HTTP origin and a wildcard Host or proxy. Refusals: `PublicIngressProfileError` naming the key. Errors never hold a secret value. Writes: none. Depends on: none. | Test: `tests/deployment/test_public_ingress_identity.py::test_valid_mapping_renders_redacted_and_each_defect_is_refused` (L1). Verified by the root slice test `tests/deployment/test_public_ingress_identity.py::test_profile_renders_origin_callback_and_proxy`. |
| `ARBORA-INGRESS-R001.2` | **Profile wiring into environment rendering.** Subsystem: deployment, public ingress. Caller: `setup-config` → `arbora/deployment/cli.py` → `arbora/deployment/genesis_environments.py::load_environment_profile` → `EnvironmentProfile.public_ingress` (new field of type `PublicIngressProfile`). Rule: the renderer emits the ingress host, TLS secret reference, callback URI and trusted proxy from the profile. It emits `identity.public_origin` into `~/.config/arbora/config.json`. WebAuthn origin, Origin verification and OIDC and SAML callbacks read that value. No domain or provider default exists. Refusals: `PublicIngressProfileError` naming the key. Writes: rendered configuration files only. Depends on: `ARBORA-INGRESS-R001.1`. | Test: `tests/deployment/test_public_ingress_identity.py::test_profile_renders_origin_callback_and_proxy` (L3). It runs the CLI render and asserts the output values and the refusal for a missing key. |
| `ARBORA-INGRESS-R001.3` | **Time-bounded legacy hostname redirect.** Subsystem: deployment, public ingress. Caller: `setup-config` render → ingress route output. Config in the profile: `legacy_hostname` and `legacy_redirect_until` (ISO date, at most 90 days after render). Rule: until that date the legacy host answers 308 to the same path on the new origin. After the date the render omits the route. A render with a date beyond 90 days refuses with `LEGACY_REDIRECT_TOO_LONG`. Writes: rendered files only. Depends on: `ARBORA-INGRESS-R001.2`. | Test: `tests/deployment/test_public_ingress_identity.py::test_legacy_redirect_is_bounded` (L1). It asserts the 308 route, the omission after the date and the refusal. |
| `ARBORA-INGRESS-R001.4` | **Cutover served probe.** Subsystem: deployment, release qualification. Caller: `scripts/identity_probe.py` of `ARBORA-IDENTITY-R024` against the new hostname. Rule: the probe completes a browser sign-in through the identity provider. It then calls the MCP and REST endpoints under the renamed ingress. Output holds no cookie or credential. Depends on: `ARBORA-INGRESS-R001.2`, `ARBORA-IDENTITY-R024`. | Test: `tests/deployment/test_public_ingress_identity.py::test_cutover_probe_signs_in_on_new_hostname` (L6). It asserts sign-in success and both endpoint answers. |
