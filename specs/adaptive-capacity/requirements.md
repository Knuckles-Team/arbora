| `ARBORA-CAPACITY-R001` | **AIMD error-budget throttling that only narrows automatically (rollup).** Subsystem: fleet admission, capacity. Entry: every served `fleet.call` records an outcome, and the controller loop started at host bootstrap closes windows. Arbora observes a bounded error budget per tenant, child and operation class.
