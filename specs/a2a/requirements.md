| `ARBORA-A2A-R002.2.2` | **Reference-bound single-tool task worker.** Model: `ToolTaskRequest`, `ToolTaskResult`, `ToolTaskCarrier`, `ToolTaskDispatcher` and `WorkItemFence` in `arbora/a2a/tool_task.py`. The carrier holds the job ID, the content-addressed request reference, the tenant, the session and one allowed tool. The request holds canonical JSON parameters, never a prompt. Behavior: `run_tool_task` claims the admitted WorkItem through the EG coordination methods. It resolves the exact request through the dispatcher inside the lease. The request digest, tenant, session and single tool must match the carrier before execution starts. The dispatcher reauthorizes the original caller and uses the job ID as its durable idempotency key. A bound result commits its receipt reference under the claim. Wiring: `arbora.a2a` exports the worker. `ARBORA-A2A-R002.2.3` owns the served queue consumer. Refusal: A missing dispatcher, a changed request or a wrong tool refuses before execution and commits a failed result. Some outcomes are uncertain: an exception after execution starts, a result for another job or caller, and an indeterminate result. Each uncertain outcome leaves the WorkItem open and the delivery unacknowledged. An expired deadline starts no execution and leaves the item open for reconciliation. A lost lease stops the worker without a commit. A terminal item skips the delivery. The worker never repeats an uncertain effect. | `tests/a2a/test_tool_task.py` covers each committed outcome, each uncertain outcome and each refusal before execution. It also covers duplicate delivery, a claim held elsewhere, an expired deadline, a foreign carrier, lease loss and canonical requests. |
