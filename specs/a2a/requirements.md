# ARBORA-A2A requirements

| ID | Requirement | Verification |
|---|---|---|
| `ARBORA-A2A-R001` | **A2A facade over the engine and agent services.** arbora implements A2A as a facade over the public graph-engine and agent-utilities services exposed through MCP and REST, starting with unary agent-card discovery and task send/get/list/cancel, then adding durable task streaming and resubscribe without a second task store. Split into `ARBORA-A2A-R001.1` (the resubscribe method-table slice) with the event-cursor-backed streaming fixture remaining open under the parent. | Proven by contract tests covering the unary task operations and a durable stream/resubscribe fixture. |
| `ARBORA-A2A-R001.1` | **Fail-closed `tasks/resubscribe` stub on the A2A method table.** arbora registers `tasks/resubscribe` in the A2A JSON-RPC method table with typed, validated params, and refuses it with a distinct error until durable, restart-safe event-cursor-backed streaming exists — never silently succeeding, never reported as an unrecognized method. | Proven by a test asserting `tasks/resubscribe` validates params and is refused with a dedicated JSON-RPC error code distinct from "method not found". |
| `ARBORA-A2A-R002` | **Inbound task routing with caller-filtered tool exposure.** arbora routes inbound A2A tasks through the existing agent orchestration port into engine-backed work items. Caller-filtered assembly selects the agent and its exposed tool subset. The caller sees only authorized tools. `ARBORA-A2A-R002.1` covers fail-closed refusal when assembly selects a tool subset. `ARBORA-A2A-R002.2` covers caller-filtered enforcement through the AU signed dispatch carrier. That child remains open under the parent. | Proven by integration tests asserting routed tasks map to durable work-item identities and exposed tool subsets match the caller's authorization. |
| `ARBORA-A2A-R002.1` | **Fail-closed refusal when assembly selects a tool subset.** arbora refuses `dispatch()` with a distinct error before durable admission when a routing decision selects a tool subset. The signed AU dispatch carrier cannot enforce an allowlist at execution time. | Proven by a test asserting dispatch raises `A2AAssemblyUnavailable` whenever `decision.selected_tools` is non-empty. |
| `ARBORA-A2A-R002.2` | **Caller-filtered tool-subset enforcement at dispatch.** The signed AU agent-dispatch carrier accepts and enforces an allowed-tool subset end to end. The caller's exposed tools match its authorization at execution time. Split into `ARBORA-A2A-R002.2.1` (the owner-named AU dependency) because arbora has no public door to add this itself. | Proven by integration tests asserting an enforced tool subset at execution, not just an advisory list. |
| `ARBORA-A2A-R002.2.1` | **Owner-blocked: AU carried, enforced tool-subset field.** `agent_utilities.orchestration.agent_dispatch.AgentTurnEnvelope`/`enqueue_agent_turn` has no field or mechanism to carry and enforce a caller-filtered tool allowlist at execution time. arbora's `WorkItemA2AAuthority._enqueue`/`dispatch` (`arbora/a2a/authority.py`) already refuse every request carrying `decision.selected_tools` (`ARBORA-A2A-R002.1`) rather than pass through an unenforced allowlist. agent-utilities owns adding that carried, enforced field. Until an agent-utilities spec exists and lands it, `ARBORA-A2A-R002.2` cannot be implemented in this repository. | No arbora-side test is possible against the current AU carrier contract. Verified by the fail-closed tests bound to `ARBORA-A2A-R002.1` continuing to refuse rather than silently drop the filter. Tracked as the explicit cross-repo dependency recorded in `tasks.md`. |
| `ARBORA-A2A-R002.2.2` | **Reference-bound single-tool task worker.** Model: `ToolTaskRequest`, `ToolTaskResult`, `ToolTaskCarrier`, `ToolTaskDispatcher` and `WorkItemFence` in `arbora/a2a/tool_task.py`. The carrier holds the job ID, the content-addressed request reference, the tenant, the session and one allowed tool. The request holds canonical JSON parameters, never a prompt. Behavior: `run_tool_task` claims the admitted WorkItem through the EG coordination methods. It resolves the exact request through the dispatcher inside the lease. The request digest, tenant, session and single tool must match the carrier before execution starts. The dispatcher reauthorizes the original caller and uses the job ID as its durable idempotency key. A bound result commits its receipt reference under the claim. Wiring: `arbora.a2a` exports the worker. The queue consumer calls it for each verified tool-task carrier, and acknowledges the delivery only when `ToolTaskRun.acknowledge` is true. Refusal: A missing dispatcher, a changed request or a wrong tool refuses before execution and commits a failed result. Some outcomes are uncertain: an exception after execution starts, a result for another job or caller, and an indeterminate result. Each uncertain outcome leaves the WorkItem open and the delivery unacknowledged. An expired deadline starts no execution and leaves the item open for reconciliation. A lost lease stops the worker without a commit. A terminal item skips the delivery. The worker never repeats an uncertain effect. | `tests/a2a/test_tool_task.py` covers each committed outcome, each uncertain outcome and each refusal before execution. It also covers duplicate delivery, a claim held elsewhere, an expired deadline, a foreign carrier, lease loss and canonical requests. |
| `ARBORA-A2A-R002.2.2.1` | **Single-invocation worker contract.** Validate canonical requests and exact carrier bindings through the exported worker. With injected dispatcher and fence ports, commit only bound outcomes. An uncertain invocation leaves the item open and unacknowledged. This child does not prove queue wiring or safety across later deliveries. | `tests/a2a/test_tool_task.py` exercises the worker contract with controlled ports. |
| `ARBORA-A2A-R002.2.2.2` | **Native WorkItem fence binding.** `EgWorkItemFence` uses the existing EG WorkItem methods and checks the current session and tenant on each transition. Admit only a visible ready item with an exact first-attempt item and payload binding. Preserve the native lease fence through renewal and commit. Never reclaim a visible started item. Cancelled and dead-letter reads require owner reconciliation and cannot authorize acknowledgment. | `tests/a2a/test_tool_task_dispatch.py` covers boundary refusals. `tests/a2a/test_tool_task_native.py` exercises real temporary EG transitions and expired-lease refusal without acknowledgment. |
| `ARBORA-A2A-R002.2.2.3` | **Served delivery and durable reconciliation.** Wire the verified queue consumer to immutable request resolution and durable original-caller authority resolution. Reauthorize the original caller before effects and use durable job idempotency. Prove restart recovery and reconciliation of uncertain effects without repeating them. A later pre-execution refusal cannot settle an earlier uncertain effect. Acknowledge only a proven outcome under the parent contract. This child remains unimplemented. | Requires served consumer tests with durable request and caller authorities, restart, revocation, duplicate delivery and uncertain-effect reconciliation. Injected ports and native fence tests alone cannot satisfy this child. |
| `ARBORA-A2A-R002.2.2.3.1` | **Immutable native request transport.** Store canonical request bytes in EG blobs, pin their native holder, and publish only their locator on the matching WorkItem. Resolve by exact job and request digest. Check tenant, current principal and the expected carrier session reference. Session equality is a data binding, not proof that the original credential remains valid. Rehash bounded bytes on every read. This supplies data only; it neither recovers caller credentials nor authorizes effects. | Controlled refusal tests and actual native storage/read tests must prove exact binding and changed-byte refusal. Served queue and credential recovery remain under the parent. |
| `ARBORA-A2A-R002.2.2.3.2` | **Served consumer and original-caller recovery.** Compose the real queue consumer, durable original-caller authority resolver and effect dispatcher.
