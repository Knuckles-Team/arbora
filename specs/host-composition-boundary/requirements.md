# GRAPHOS-HOST requirements

| ID | Requirement | Verification |
|---|---|---|
| `GRAPHOS-HOST-R001` | **Cross-repository composition boundary assignment.** GraphOS composes its runtime gateway on top of boundary contracts in which the graph engine owns ontology, SHACL and durable graph records, the connector SDK owns connector transport, and the agent runtime exposes only its public agent control-plane API; the web UI consumes this composed boundary rather than any internal package. | An import-boundary census confirms each dependency is reached only through its published public API, enforced as a continuous-integration check. |
| `GRAPHOS-HOST-R002` | **Graph engine client exposes the session/discovery surface.** The graph engine's client library exposes session, engine, source-sync, shard-topology, fleet-catalog and discovery-authority methods that GraphOS's gateway and fleet modules call directly, so migrating that code out of the agent runtime does not require reimplementing this surface. | A contract test against the installed graph engine client confirms each required method is present and callable before the dependent modules are migrated. |
| `GRAPHOS-HOST-R003` | **Web UI rename cutover across GraphOS.** GraphOS's import sites, optional web UI package extra, package source reference, release workflow checkout step, preflight checks, and browser-control tests and docs all reference the renamed web UI package. | A focused test run and the offline lock check confirm every reference resolves against the renamed package. |
| `GRAPHOS-HOST-R004` | **Single gateway implementation under graph_os/gateway.** GraphOS retains one gateway implementation under `graph_os/gateway/`, incorporating any behavior unique to the agent runtime's duplicate gateway package once that duplicate is removed, reconciling the `schemas/graph_core` and `ontology_api` modules against their counterparts, and dropping the `graph-os-daemon` console script and the `gateway-widgets` package extra. | A package-layout test confirms no duplicate gateway implementation remains and the retired script and extra are absent. |
